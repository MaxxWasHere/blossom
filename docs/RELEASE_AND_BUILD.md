# Release model and builds

## Stable vs beta

| | Stable | Beta |
|---|--------|------|
| Repo | [MaxxWasHere/blossom](https://github.com/MaxxWasHere/blossom) | [MaxxWasHere/blossombeta](https://github.com/MaxxWasHere/blossombeta) |
| License | None | Key required |
| Build flag | `BUILD_CHANNEL=stable` | `BUILD_CHANNEL=beta` |

Stable is open source (Apache 2.0). Tag each stable release (`v2.x.0`). Beta exes go to `blossombeta` as pre-releases. When beta is ready, merge to `main`, bump stable version, tag, build stable exe, upload to Blossom releases.

## Repo layout

- App entry: `run_local_ui.py` (implementation in `src/`)
- Specs: `BlossomMacro.spec` (stable), `BlossomMacro-beta.spec` (beta)
- License worker: `license-server/`
- Version numbers — keep aligned before release:
  - `scripts/build_all.py` → `DEFAULT_STABLE_VERSION` / `DEFAULT_BETA_VERSION`
  - `src/blossom_updater.py` → `STABLE_VERSION` / `BETA_VERSION`
  - Git tag / release title
- `src/blossom_build_info.py` is generated by the build script, not hand-edited for releases

## Build

**Prereqs:** Python 3.11+, `pip install -r requirements.txt`

**Local dev (no license gate):**

```powershell
py run_local_ui.py
```

**Release exes** (close running Blossom first):

```powershell
py scripts\build_all.py all --stable-version 2.0.0 --beta-version 2.1.0-beta.1 -o dist\2.0.0
py scripts\build_all.py stable 2.0.0 -o dist\2.0.0 --push-repo
py scripts\build_all.py beta 2.1.0-beta.1 -o dist\2.1.0-beta.1
```

`--push-repo` (stable only): commits and pushes source to [MaxxWasHere/blossom](https://github.com/MaxxWasHere/blossom) after the exe is built. Use this for every stable release.

Output: `Blossom-{version}.exe`.

| Channel | Spec | Upload |
|---------|------|--------|
| stable | `BlossomMacro.spec` | [blossom releases](https://github.com/MaxxWasHere/blossom/releases) |
| beta | `BlossomMacro-beta.spec` | [blossombeta releases](https://github.com/MaxxWasHere/blossombeta/releases), mark pre-release |

Optional: `py scripts\build_all.py beta 2.1.0-beta.1 --obfuscate` (PyArmor on `src/blossom_license.py`).

After building, bump `src/blossom_updater.py` to match and upload assets with the exact exe names.

## Promote beta → stable

1. Merge beta into `main`.
2. Set `STABLE_VERSION` / `DEFAULT_STABLE_VERSION` to the new version.
3. `py scripts\build_all.py stable 2.1.0 -o dist\2.1.0`
4. Tag `v2.1.0`; upload `Blossom-2.1.0.exe` to Blossom (not pre-release).
5. Start next beta: bump `BETA_VERSION`, build, upload to blossombeta.

See [`UPDATE_RELEASE.md`](UPDATE_RELEASE.md) for updater details.
