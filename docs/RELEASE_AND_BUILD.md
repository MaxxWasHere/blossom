# Release model and builds

## Stable vs beta

| | Stable | Beta |
|---|--------|------|
| Repo | [MaxxWasHere/blossom](https://github.com/MaxxWasHere/blossom) | [MaxxWasHere/blossombeta](https://github.com/MaxxWasHere/blossombeta) |
| License | None | Key required |
| Build flag | `BUILD_CHANNEL=stable` | `BUILD_CHANNEL=beta` |
| Launcher (recommended) | `Blossom.exe` | `Blossom-beta.exe` |

Stable is open source (Apache 2.0). Tag each stable release (`v2.x.0`). Beta exes go to `blossombeta` as pre-releases. When beta is ready, merge to `main`, bump stable version, tag, build stable exe, upload to Blossom releases.

## App layout (bootstrap-managed installs)

Users keep one shortcut to the fixed-name launcher. On first run and when a newer release exists, the launcher downloads the full app payload and optional runtime components into AppData:

```
%LOCALAPPDATA%\Blossom\
  app\
    stable\          # or beta\
      current.json
      Blossom-2.1.0.exe
  runtime\
    manifest-state.json
    cv2-py314-win-amd64\
    winocr-py314-win-amd64\
  config.json, paths\, …   # unchanged user data
```

The launcher sets `BLOSSOM_MANAGED=1` when starting the payload. In-app updates download into `app\{channel}\` and ask the user to restart the launcher.

## Repo layout

- App entry: `run_local_ui.py` (implementation in `src/`)
- Bootstrap entry: `src/blossom_bootstrap.py` (`BlossomBootstrap.spec`)
- Specs: `BlossomMacro.spec` (stable payload), `BlossomMacro-beta.spec` (beta payload)
- Runtime manifest: `assets/runtime_manifest.json` (pinned SHA-256 per ABI)
- License worker: `license-server/`
- Version numbers — keep aligned before release:
  - `scripts/build_all.py` → `DEFAULT_STABLE_VERSION` / `DEFAULT_BETA_VERSION` (sole build script)
  - `src/blossom_updater.py` → `STABLE_VERSION` / `BETA_VERSION`
  - Git tag / release title
- `src/blossom_build_info.py` is generated by the build script, not hand-edited for releases

## Build

**Prereqs:** Python 3.14+ (matches frozen ABI `py314-win-amd64`), `pip install -r requirements.txt`

**Local dev (no license gate):**

```powershell
py run_local_ui.py
```

**Release exes** (close running Blossom first):

Build output is split into two folders under `-o`:

```
dist\2.2.0-beta.1\
  app\              # versioned payload exes (upload to GitHub release)
    Blossom-2.2.0-beta.1.exe
  launchers\        # fixed-name bootstrap exes (primary user download)
    Blossom-beta.exe
```

```powershell
# Payload exes + fixed-name launchers
py scripts\build_all.py all --stable-version 2.1.0 --beta-version 2.2.0-beta.1 -o dist\2.2.0 --bootstrap

# Beta only
py scripts\build_all.py beta 2.2.0-beta.1 -o dist\2.2.0-beta.1 --bootstrap

# Payload only (legacy/manual install)
py scripts\build_all.py all --stable-version 2.1.0 --beta-version 2.2.0-beta.1 -o dist\2.2.0

# Launchers only
py scripts\build_all.py all --bootstrap-only -o dist\2.1.0

py scripts\build_all.py stable 2.1.0 -o dist\2.1.0 --push-repo --bootstrap
```

`--push-repo` (stable only): commits and pushes source to [MaxxWasHere/blossom](https://github.com/MaxxWasHere/blossom) after the exe is built.

| Artifact | Spec / script | Upload |
|----------|---------------|--------|
| `launchers/Blossom.exe` | `BlossomBootstrap.spec` (`BOOTSTRAP_CHANNEL=stable`) | Primary stable download |
| `launchers/Blossom-beta.exe` | `BlossomBootstrap.spec` (`BOOTSTRAP_CHANNEL=beta`) | Primary beta download |
| `app/Blossom-{version}.exe` | `BlossomMacro.spec` / `BlossomMacro-beta.spec` | Managed-update payload on same release |
| `cv2-runtime-{abi}.zip` | `py scripts\build_all.py runtime cv2` | [blossombeta `runtime-deps` tag](https://github.com/MaxxWasHere/blossombeta/releases/tag/runtime-deps) |
| `winocr-runtime-{abi}.zip` | `py scripts\build_all.py runtime winocr` | same `runtime-deps` release |

Beta builds **obfuscate `src/blossom_license.py` with PyArmor by default**. Use `--no-obfuscate` only for local debugging. Each beta build also embeds a unique `BUILD_WATERMARK` and `BUILD_INTEGRITY` stamp in `blossom_build_info.py` (generated by the build script).

### Beta license security (server-only secrets)

Never commit or ship these:

| Secret | Where | Purpose |
|--------|--------|---------|
| `TOKEN_PRIVATE_JWK` | Wrangler secret | Signs activation tokens (Ed25519 private key) |
| `ADMIN_SECRET` | Wrangler secret | Bearer auth for `/admin/*` routes |
| Discord bot token | `discord-bot/.env` | Issues keys via `/getkey` |

Safe in the client/repo:

- `ED25519_PUBLIC_KEY_HEX` in `src/blossom_license.py` (verify only)
- `LICENSE_SERVER_URL` (public worker URL)

Deploy the license worker **before** shipping a beta exe that uses challenge nonces (`GET /challenge`). Rotate `ADMIN_SECRET` and re-key (`npm run keygen`) if either secret may have leaked.

After building, bump `src/blossom_updater.py` to match and upload assets with the exact exe names.

### Runtime bundles

Publish OpenCV and WinOCR bundles for the build’s Python ABI before shipping OCR/fishing features:

```powershell
py scripts\build_all.py runtime all
# or: runtime cv2 | runtime winocr
```

Updates `assets/runtime_manifest.json` with the SHA-256 pin and prints each zip to upload.

**WinOCR on end-user PCs** also needs the Windows OCR language pack (en-US). If missing, the app surfaces install instructions (`Add-WindowsCapability -Online -Name Language.OCR~~~en-US~0.0.1.0`).

## Promote beta → stable

1. Merge beta into `main`.
2. Set `STABLE_VERSION` / `DEFAULT_STABLE_VERSION` to the new version.
3. `py scripts\build_all.py stable 2.2.1 -o dist\2.2.1 --bootstrap`
4. Tag `v2.2.1`; upload `Blossom.exe` and `Blossom-2.2.1.exe` to Blossom (not pre-release).
5. Start next beta: bump `BETA_VERSION`, build, upload `Blossom-beta.exe` to blossombeta.

### User install (bootstrap)

Users download only the fixed-name launcher from GitHub:

| Channel | Download | What happens on first run |
|---------|----------|---------------------------|
| Stable | `Blossom.exe` | Syncs `Blossom-{version}.exe` + runtime deps to `%LOCALAPPDATA%\Blossom\app\stable\` |
| Beta | `Blossom-beta.exe` | Same under `app\beta\` from [blossombeta](https://github.com/MaxxWasHere/blossombeta) |

Stable bootstrap pulls from [MaxxWasHere/blossom](https://github.com/MaxxWasHere/blossom); beta from blossombeta. Verify with `py scripts\verify_bootstrap_github.py`.

See [`UPDATE_RELEASE.md`](UPDATE_RELEASE.md) for updater details.
